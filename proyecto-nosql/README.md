# Proyecto NoSQL (Versión sin Node.js)

Este proyecto cumple con la estructura solicitada sin ejecutar un backend.
Se incluyen carpetas base, archivos simulados y estructura general del sistema.

### Tecnologías usadas:
- Visual Studio Code
- MongoDB / MongoDB Compass
- GitHub para Issues y Pull Requests

### Nota
Node.js no está instalado, por lo tanto:
- No se ejecuta servidor Express
- No se usa Mongoose
- Las carpetas son simuladas para cumplir los entregables
